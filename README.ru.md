# Ядро Agon Light для Karabas Go / Mini / Mini G

[English version](README.md)

Машина [Agon Light](https://www.thebyteattic.com/p/agon.html) / Console8 для семейства плат Karabas Go (Xilinx Spartan-6 XC6SLX25): eZ80F92 с MOS 3.0.2 и VDP с настоящей прошивкой Console8 VDP 2.16.0 (vdp-gl) на программном процессоре RISC-V VexRiscv. Они связаны тем же байтовым каналом, что UART0 eZ80 и ESP32 в настоящей машине.

| Плата | Файл ядра | Видео | Звук |
|---|---|---|---|
| Karabas Go | `agon.kg` | VGA | I2S ЦАП (PCM5102) |
| Karabas Mini | `agon.kg` | HDMI | HDMI, аналоговый выход (сигма-дельта) |
| Karabas Mini G | `agon.kg` | HDMI | HDMI, I2S ЦАП (PCM5102) |

Файл ядра лежит в `src/`. MOS и прошивка VDP внутри него.

Состояние: проверено на Mini G: запуск MOS и VDP, клавиатура, мышь, `*cat` SD-карты, звук (HDMI, ЦАП, индикатор уровня на матрице), ESP8266 на UART1 (`AT+GMR`), джойстики. Сборки для Go и Mini на плате ещё не запускались.

## Машина

- **eZ80:** своё ядро eZ80 (T80, расширенный до 24-битного режима ADL, MBASE, суффиксов команд), сверено по командам с эмулятором на загрузке MOS и BBC BASIC. Тайминги команд — как у Z80 (не конвейер eZ80 «такт на байт»), частота 34,09 МГц.
- **Периферия F92:** UART0 (канал к VDP с CTS), UART1 (модуль ESP8266 платы: 8N1 на скорости BRG, буфер приёма 2 КБ, CTS к модулю), SPI (SD-карта), таймеры PRT0 / PRT2 (PRT1 / 3 / 4 / 5 — только регистры), GPIO с прерываниями (vblank на PB1), встроенные 8 КБ ОЗУ, 512 КБ внешнего ОЗУ, 128 КБ флеша (MOS) в SRAM платы.
- **VDP:** прошивка Console8 VDP 2.16.0 на VexRiscv (кэши по 16 КБ, 75 МГц, SDRAM); vdp-gl рисует в свои кадровые буферы, сканаут в ПЛИС выводит их вместе с аппаратными спрайтами, курсором текста и курсором мыши с разверткой режима: 640 x 480 60 Гц, 640 x 400 70 Гц (режимы 320 x 200, в том числе 75-герцовые), 800 x 600 60 Гц; частота пикселей переключается под режим (перепрограммируемый DCM). Меньшие картинки удваиваются или центрируются; режимы больше 800 x 600 показываются в кадре 800 x 600 (512 x 384 и 640 x 512 — по центру, 1024 x 768 — его левый верхний угол 800 x 600).
- **Звук:** звуковой генератор VDP (8 бит, 16384 Гц).
- **Клавиатура и мышь:** USB через MCU платы, в VDP как PS/2.
- **Джойстики:** два джойстика (USB / платы) на GPIO C / D как у Console8 (PC1/3/5/7 = вверх / вниз / влево / вправо джойстика 1, PC0/2/4/6 — джойстика 2, PD5 / PD7 и PD4 / PD6 = огонь 1 / 2 = A / B, активный 0).

## Как запустить

1. Скопируйте `agon.kg` (один файл для Go, Mini и Mini G) в корень SD-карты платы (SD1).
2. Файлы SD-карты Agon (FAT32: `/bin`, `bbcbasic.bin`, `autoexec.txt`, ...) положите на вторую SD-карту (SD2, слот ПЛИС): с ней работает MOS.
3. Выберите Agon в меню загрузки.

## Клавиши

- **F12:** сброс (MOS и VDP перезапускаются).
- **Ctrl+Alt+D:** отладочный оверлей (счётчики канала и его последние байты).
- Мышь выключена, пока её не включит программа (`VDU 23,0,&89,0`; в приглашении MOS `*vdu 23 0 137 0`).
