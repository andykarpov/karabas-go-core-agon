# Agon Light core for Karabas Go / Mini / Mini G

Work in progress. An [Agon Light](https://www.thebyteattic.com/p/agon.html) / Console8 machine (eZ80F92, MOS, BBC BASIC, VDP) for the Karabas boards (Spartan-6 XC6SLX25). The plan (in Russian) is in [docs/PLAN.md](docs/PLAN.md).
